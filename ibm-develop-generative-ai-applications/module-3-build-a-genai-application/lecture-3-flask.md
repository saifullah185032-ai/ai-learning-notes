# Professional Notes: Introduction to Flask

## 1. Overview of Flask

- Flask is a micro web framework created by Armin Ronacher in 2004.

- Known for being lightweight, unopinionated, and highly extensible.

- Suitable for building web applications with minimal setup.

## 2. Key Features of Flask

- Built‑in development web server.

- Integrated debugger with interactive traceback.

- Uses Python logging for application logs.

- Supports testing workflows (e.g., pytest, coverage).

- Direct access to request and response objects.

- Support for static assets (CSS, JS, images).

- Jinja templating for dynamic pages.

- Routing with dynamic URLs suitable for RESTful services.

- Global error handling.

- User session management.

## 3. Popular Flask Extensions

- Flask‑SQLAlchemy: ORM support.

- Flask‑Mail: SMTP mail server integration.

- Flask‑Admin: Admin interfaces.

- Flask‑Uploads: File upload handling.

- Flask‑CORS: Support for CORS.

- Flask‑Migrate: Database migrations.

- Flask‑User: Authentication & authorization.

- Marshmallow: Serialization/deserialization.

- Celery: Background task queue.

## 4. Installation Notes

- Recommended to use virtual environments (venv).

- Flask 2.2.2 requires Python 3.7+.

- Install via pip with version pinning for reproducibility.

## 5. Built‑in Dependencies

- Werkzeug: WSGI implementation.

- Jinja: Template rendering engine.

- MarkupSafe: Prevents injection in templates.

- ItsDangerous: Secure data signing.

- Click: Command‑line interface framework.

## 6. Flask vs Django

- Flask is lightweight and flexible.

- Django is a full‑stack, opinionated framework.

- Flask provides minimal base; Django bundles all components.

- Flask promotes plug‑and‑play extensibility; Django enforces structure.
