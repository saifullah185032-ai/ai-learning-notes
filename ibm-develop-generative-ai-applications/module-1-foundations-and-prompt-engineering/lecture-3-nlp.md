# Natural Language Processing (NLP) – Key Notes

## Definition

- NLP is the process of enabling computers to understand and process human language.

- It bridges unstructured text (human speech/writing) and structured data (computer-readable format).

## Core Components

- NLU (Natural Language Understanding): Converts unstructured text to structured data.

- NLG (Natural Language Generation): Converts structured data back to human-readable text.

## Common Use Cases

- Machine Translation: Translating languages while preserving context.

- Virtual Assistants & Chatbots: Interpreting spoken or written commands.

- Sentiment Analysis: Detecting tone or sentiment in text (e.g., positive/negative reviews).

- Spam Detection: Identifying spam emails based on content patterns.

## How NLP Works

- Input: Unstructured text (spoken or written).

- Key Processes:

- Tokenization: Breaking text into smaller units (tokens).

- Stemming: Reducing words to their root form (e.g., running → run).

- Lemmatization: Using dictionary meaning to find root (e.g., better → good).

- Part-of-Speech Tagging: Identifying grammatical roles (noun, verb, etc.).

- Named Entity Recognition (NER): Detecting entities like names, places, organizations.

## Tools & Techniques

- NLP uses a combination of algorithms and linguistic tools rather than a single method.

## Applications

- AI systems, search engines, voice assistants, text analytics, and more.
